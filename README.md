# DaD Hexcrawl Adventure Generator

Одностраничный генератор гекскроула по «Dragons at Dawn: Supplement I — Twilight» (Daniel Hugh Boggs, 2011).

Открыть: https://dexius9669.github.io/hexcrawl/

## Файлы

- `DaD_Hexcrawl.html` — самодостаточный генератор (без внешних зависимостей, открывается прямо в браузере).
  Три вкладки: «Броски по таблице», «Генератор карты», «Генератор встреч».
- `AGENTS.md` — правила проекта для агентов (структура таблиц, OCR-артефакты, лицензия).
- `progress.md` — состояние проекта и осознанные пробелы книги.

## Лицензия

Unofficial unlicensed product designed for use with Dragons at Dawn. Not affiliated with
Southerwood Publishing. Все правила генератора выводятся из исходного текста книги.

Исходный OCR-текст правил (`DaD.md`) в репозиторий не включён — он остаётся локальным
источником истины.
